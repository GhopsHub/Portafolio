# Portafolio

Proyecto de portafolio creado con React, TypeScript, Vite y Tailwind CSS.

## Estructura

```text
src/
  assets/      Fuentes, estilos e imagenes
  components/  Componentes reutilizables
  data/        Datos de proyectos y habilidades
  lib/         Utilidades compartidas
  pages/       Vistas principales y detalles
```

## Comandos

```bash
npm install
npm run dev
npm run build
```
